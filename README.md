# 北區營運處 EIP 營運工作台

正式網站：https://hippop3c.github.io/EIP/

## 營運指標管理簡報

[下載 2026-11-11 營運指標管理建議簡報](./reports/eip-operations-kpi-20261111.pptx)（22 頁，可編輯 PowerPoint）。依既有表單提出八項指標、推薦原因、計算方式與導入建議，附 58 入口清單。[提案摘要與來源限制](./reports/README.md)。

調度、維護、客服三組共 58 份表單／專案分頁。開啟即載入清單，支援搜尋、分組、最愛、最近開啟、跨組勾選進度彙整、複製、CSV 下載及深色模式。勾選與最愛只存在個人瀏覽器。

## 資料與更新

- 目錄依 2026-11-06 的「北營處客服+調度組-統計報表連結v1.xlsx」建立，維護工作簿展開為 17 個專案分頁。
- `data/dashboard.json` 只保存已核對的彙總與來源連結，不含帳密、Google 登入資訊、人名、電話、車牌或原始明細。
- 「更新進度」直接重讀已核對且可公開讀取的 Google CSV 摘要；來源格式改變、需要登入或讀取失敗時，明示錯誤並保留原快照，不會改成零。
- 客服異常表須登入，這次以有權限帳號匯出核對後建立快照。GitHub Pages 本身不會取得 Google 登入資訊，也不能自動更新受保護資料。重新取得有權限資料後，應更新對應快照並核對期間與來源。
- 來源清單中的 17 份線下表單沒有檔案或連結，已明示待提供資料。未能建立可靠摘要的其他表單仍保留入口，並說明可核對的範圍。
- 8 份調度表單已以提供帳戶登入逐一確認仍要求存取權，沒有發出權限申請；另有 4 份指定分頁為空白或未填範本。
- 擷取時間、來源資料日期、目錄修改時間各自顯示。沒有資料日期時不以擷取時間代替。

## 已核對的重點定義

- 車況：以「車輛里程總表」列管車號去重；有註記不等於故障，未填不等於正常，列管數不等於目前可用數。只輸出聚合。
- 人力：以「計算」分頁三個互斥分區合計交叉核對，FT／PT 分開呈現。
- 維護：以「追蹤專案_2.0E無助力」分類與總計核對，保留原表達成率。
- 客服：本週為部分填報；原週表的「嘉義／嘉縣」名稱差異造成漏計，網站並列原表與日表差異，未修改來源。2026/10 完整月已逐格核對。

## 開發與部署

無外部套件，直接以 GitHub Pages 的 `main` 根目錄發布。

```sh
node scripts/serve.mjs
node --test tests/progress.test.js
node scripts/update-snapshot.mjs
```

更新腳本只更新已支援的公開摘要，受保護資料與缺少來源的項目保留原狀。更新失敗會返回非零結束碼。沒有排程或背景自動發布。
